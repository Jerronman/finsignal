How it decides to buy or sell

Every …, the app pulls general financial news from Marketaux, which tags each article with the real stock tickers it's about. For every tagged symbol, Claude judges the likely short-term price reaction as buy, sell, or hold, with a confidence score and one sentence of reasoning.

A verdict only becomes a trade if it clears every guardrail:

  • hold, or confidence below … → skipped
  • That symbol already traded within the last … → skipped
  • sell with no existing position in that symbol → skipped (no shorting)
  • Alpaca can't actually trade the symbol (foreign listing, inactive/expired warrant, etc.) → skipped

If none of those block it: buy submits a market order sized between … and …, scaled by confidence; sell closes the existing position entirely.

Take-profit strategy

Independent of the news signal — this only watches your own entry price, checked roughly every …. As a position gains value since you bought it (not "today's" move), a fraction of the original share count is sold off at each tier crossed:

Gain since entryActionCumulative sold

Each tier fires once per position. If the price jumps past several tiers between checks (a gap move), all newly-crossed tiers fire in the same pass rather than only the highest one. "Original" share count is set the first time this checker sees the position open — if you buy more of the same symbol later while a plan is already tracking it, those extra shares aren't folded into the plan until the position fully closes and a fresh one starts on the next buy.

No downside protection yet. There's no stop-loss — a position that loses value has no automatic exit here. It only closes if a fresh bearish news item produces a sell verdict for that specific symbol. This is a deliberate, known gap, not an oversight.

Options strategy

A separate pipeline that reuses the exact same news verdicts as stocks above (no extra Marketaux calls) but always trades options instead: a buy verdict Buy-to-Opens a call, a sell verdict Buy-to-Opens a put. Never writes/sells options short, never reacts to hold.

  • Confidence below … → skipped (its own bar, separate from the stock one above)
  • That underlying already options-traded within the last … → skipped
  • Strike: nearest available to … out of the money
  • Expiration: nearest Friday at least 2 days out — a signal on Thursday or Friday rolls to the following week instead
  • Liquidity: skipped if open interest is below …, or the bid-ask spread is wider than … of the midpoint, or there's no real bid at all
  • Sizing: up to … per trade — floor(budget / (ask price × 100)) contracts, skipped entirely if even 1 contract exceeds the budget

Take-profit tiers, checked roughly every …, same ratchet mechanic as stocks but keyed off the option's own gain since entry:

Gain since entryActionCumulative sold

Forced close the Thursday before expiration, regardless of P&L. This is a time-based exit, not a loss-based stop — a losing contract is never cut early, it rides all the way to that Thursday and is then sold for whatever it's worth, however little. There is no stop-loss for options, by explicit choice.
